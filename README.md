# Kith

Self-hosted personal knowledge graph over your correspondence — email first, then documents and chats. Ask questions about your past with cited answers, search and read threads, and explore the people, organisations, events and commitments in your life.

> **Status: planning.** Requirements and architecture are being written; no code yet.

## Planned

- **Connectors:** Gmail (All Mail incl. Sent, labels, categories), other mailboxes, Paperless-ngx documents, chat exports
- **Ask:** natural-language questions answered with citations to the source threads (GraphRAG)
- **Search + reader:** filtered search (person, organisation, date, label) and a clean thread view
- **People & organisations:** profile pages, timelines, amounts and commitments
- **Graph explorer / timeline**
- **Multi-tenant, self-hosted, local-model friendly** (OpenAI-compatible endpoints, OIDC login)
